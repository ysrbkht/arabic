# قواعد اللغة العربیة — کتابخانه تعاملی

هر قاعده یک صفحه مستقل با ارائه گام‌به‌گام، حالت شب/روز، نشانگر لیزری،
کارگاه تعاملی و آزمون کلاسی است.

## اجرا
- مستقیم `index.html` را باز کنید، یا
- با یک سرور ساده: `python3 -m http.server` و سپس `http://localhost:8000`

## افزودن قاعده جدید
1. یک فایل در `rules/` بسازید (از یکی از فایل‌های موجود کپی کنید).
2. `window.ARABIC_RULE` را با محتوای خود پر کنید.
3. یک خط به `assets/rules.js` اضافه کنید.
