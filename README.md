# قواعد اللغة العربیة — کتابخانه تعاملی

مجموعه‌ای از ارائه‌های تعاملی و لوح‌های آموزشی برای تدریس قواعد زبان عربی.

## ساختار

- `rules/` — ارائه‌های تعاملی گام‌به‌گام (با کارگاه و آزمون)
- `posters/` — لوح‌های آموزشی آمادهٔ چاپ و دانلود PNG
- `assets/` — موتور مشترک، استایل و فهرست قواعد

## اجرا

- مستقیم `index.html` را باز کنید، یا
- با یک سرور ساده: `python3 -m http.server` سپس `http://localhost:8000`

## افزودن قاعده جدید (ارائه تعاملی)

1. از یکی از فایل‌های `rules/*.html` کپی بگیرید.
2. `window.ARABIC_RULE` را با محتوای خود پر کنید.
3. یک خط به `assets/rules.js` اضافه کنید با `type: 'deck'`.

## افزودن لوح جدید (پوستر)

1. از یکی از فایل‌های `posters/*.html` کپی بگیرید.
2. یک خط به `assets/rules.js` اضافه کنید با `type: 'poster'`.

## کار بدون اینترنت

فونت‌ها و `html2canvas` داخل `assets/` هستند و `sw.js` همهٔ فایل‌ها را کش می‌کند. پس از یک بار باز کردن سایت (روی http/https، مثلاً GitHub Pages) برنامه آفلاین هم کار می‌کند. با افزودن فایل جدید، نام آن را در `sw.js` اضافه و نسخهٔ `CACHE` را بالا ببرید.

## خروجی لوح‌ها

- PNG: `assets/poster-export.js` (همیشه با چیدمان دسکتاپ، مقیاس خودکار تا ۳×).
- PDF: دکمهٔ چاپ؛ `assets/poster.css` لوح را روی یک صفحهٔ A3 عمودی جا می‌دهد.

## انتشار روی GitHub Pages

1. همهٔ فایل‌ها (به‌همراه `.nojekyll`) را در شاخهٔ `main` مخزن بگذارید.
2. Settings ← Pages ← Source: «Deploy from a branch» ← `main` / `/ (root)`.
3. چند دقیقه بعد سایت روی `https://<user>.github.io/<repo>/` بالا می‌آید.

### اگر صفحهٔ سفید دیدید

- مطمئن شوید `index.html` و فایل‌های `rules/*.html` روی GitHub **خالی (۰ بایت)** نیستند.
- در مرورگر Hard Refresh بزنید (`Ctrl+Shift+R`)؛ اگر سرویس‌ورکر نسخهٔ قدیمی را کش کرده، یک بار از DevTools ← Application ← Service Workers گزینهٔ Unregister را بزنید.
- سرویس‌ورکر فایل‌های HTML/JS/CSS را اول از شبکه می‌گیرد، پس بعد از هر انتشار نیازی به بالا بردن نسخه نیست. فقط هنگام **افزودن فایل جدید** نامش را به لیست `FILES` در `sw.js` اضافه کنید تا آفلاین هم کار کند.
